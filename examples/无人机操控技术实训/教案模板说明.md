## 教案（付页）结构

两栏式：**教学内容 | 教学活动**，按教学主题展开，右侧教学活动对应：
- 教师说课 / 讲解
- 师生共同讨论
- 教师提问，学生讨论
- 学生练习时间

## 与技能输出字段的对应关系

技能 `generate_lesson_plans.py` 生成的教案表格字段与此模板一一对应：

| 技能表格字段 | 教案模板对应 |
|---|---|
| 教案标题 | 教学主题/任务（10-20 字规范） |
| 知识目标 / 能力目标 / 素养目标 | 知识、能力、素养教学目标 |
| 教学重点 / 教学难点 | 教学重点 / 教学难点 |
| 布置作业 | 布置作业（有/无） |
| 教学实施 | 教学实施过程设计 |
| 课程思政 | 课程思政（思政元素融入手段、方法） |

## 教学载体 / 媒介枚举（教务系统字典表）

- **教学组织形式**：集中授课、理实一体、分组讨论、实训、实习、习题课、课堂测试、集体参观、企业讲座、翻转课堂、现场教学、项目导向、其他
- **教学载体**：子项目、任务、案例、教学软件、教材、工作页、手册、凭证/票据、设计方案/图表、文献资料网、课程平台、新媒体、实物、课件、手机、习题库、专业教学设备、黑板（白板）、粉笔、其他
- **教学媒介资源**：工具、仪器、教学挂图、技术手册、文献资料、影像资料、计算机、工单、多媒体设备、设计方案/图表、教具/模型、标本/图片、实物、课件、手机、习题库、专业教学设备、黑板（白板）、粉笔、其他

> 实训课配置建议：载体勾选"教材/工作页/手册"+"专业教学设备/课件"；媒介勾选"多媒体设备/专业教学设备/课件"等，按实际使用情况勾选。
