# 示例：无人机操控技术实训（上电真实课程材料）

本目录是 `lesson-plan-batch-workflow` 技能的**真实课程示例**，以《无人机操控技术实训》为例，
材料取自上海电子信息职业技术学院（上电）中德工程学院无人机应用技术专业 2022-2023 学年第 1 学期
实际授课文档，供其他老师上手测试、调整文案、以及按课程标准对课程安排做分析处理。

## 数据来源与口径

| 材料 | 来源文件 | 说明 |
|---|---|---|
| 30 课次安排（周次/日期/内容/形式/作业） | 教学进程表 .doc | 2022-2023 学年第一学期，周次 7-18，每次课 2 学时 |
| 课程结构（三模块/学时/目标/考核） | 课程标准.pdf | 模拟驾驶 32h + 室内飞行 16h + 室外飞行 16h = 64h |
| 教案字段与字典表 | 导入教案.xls、教案-01、02.doc | 教务系统 24 列导入模板 + 教案首页/付页结构 |
| 第一课次课件要点 | 无人机操控技术实训.ppt | 实验室规则、法规文件、安全要求 |

- 班级示例为 **22无人机1**（取自教案模板与教学进程表）；"节次、地点"源材料未提供，示例中留空，
  实际使用请按教务系统排课填写。
- 星期由日期自动计算（`2022-10-18` 为星期二等），与教案模板执行日期一致。
- 多班级场景：复制 `授课计划.csv` 中行并把"班级"列改为目标班级（如 25无人机2）、日期替换为
  该班级实际排课日期，脚本会按班级分组各输出一份教案表。

## 快速上手（复现示例）

```bash
# 1. 解析授课计划（CSV/xls/xlsx/docx/pdf 均可）
python scripts/parse_teaching_plan.py 授课计划.csv --out 授课计划_parsed.json

# 2. 编辑教案内容（按课程标准/个人风格调整各字段文案）
#    → 教案内容.json

# 3. 生成教案表格（每班一份 xlsx）
python scripts/generate_lesson_plans.py --plan 授课计划_parsed.json --content 教案内容.json --out .

# 4. （可选）登录教务系统按 references/form-filling.md 逐课次填入，默认暂存
```

> 技能根目录：`skill 安装后路径/lesson-plan-batch-workflow/`；脚本位于其 `scripts/` 下。

## 按课程标准管理课程安排（示例分析口径）

以课程标准三模块为主线，30 课次可归并为：

- **模块一 无人机模拟驾驶（课次 1-12）**：课程概述与飞行安全（1-2）→ 环境安装与遥控器配置（3-5）→
  起降/悬停（6）→ 匀速/升降/菱形（7）→ 矩形/米字（8）→ 水平360/有风悬停（9-10）→ 八字飞行（11）→
  模拟飞行考核（12）
- **模块二 室内飞行（课次 13-19）**：电池充电/安装解锁（13）→ 起降悬停（14）→ 八面悬停（15）→
  四面矩形（16）→ 偏转360（17）→ 水平8字（18）→ 室内考核（19）
- **模块三 室外飞行（课次 20-28）**：安全检查（20）→ 电池充电/安装解锁（21-22）→ 起降悬停（23）→
  八面悬停（24）→ 四面矩形（25）→ 偏转360（26）→ 水平8字（27）→ 室外考核（28）
- **综合考核（课次 29-30）**：期末考核

考核口径：模拟/室内/室外三阶段平时考核 + 期末综合考核，与课程标准"过程考核 60% + 平时考核 40%"
结构对应；教学实施统一采用"任务导入→教师演示→学生操作→教师指导→学生评价→教师评价→知识点讲解→
总结拓展"八步活动设计。

## 调整提示

- 改文案：直接编辑 `教案内容.json` 中的各字段，重新运行第 3 步即可重新出表。
- 换课程/班级：替换 `授课计划.csv` 行内容（主题/日期/班级），并相应调整教案内容 JSON。
- 对接教务系统：见技能 `references/form-filling.md`（DOM 探测、字段映射、暂存/提交）。
